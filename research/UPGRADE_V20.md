# 합성사용 재평가 반영 v20

2026-09-29 · 대상: 로컬 장소 비교 앱

근거는 [합성지침 v2](SYNTHETIC_GUIDE_V2.md), [v19 재평가](SYNTHETIC_RECHECK_V19.md),
[기존 100개 조건](recheck_v19_cases.csv)이다. **실제 참가자 0명**이며,
이 기록은 구현 대응과 일부 대표 화면 관찰이다. 100명이 사용했거나 각 조건을
독립적으로 실행했다는 뜻이 아니다. 만족도·선택 성공률·현장 사용성 점수를 만들지 않았다.

## 바꾼 사용자 흐름

1. 사진·한 줄 경험을 보고 비용과 기본 운영·휴관을 같은 표에서 대조한다.
2. 부족한 정보는 운영 행의 관련 안내 또는 상세 첫 화면의 안내·전화에서 확인한다.
3. 둘 다 맞지 않으면 ‘두 곳 모두 어렵다면’을 펼쳐 기존의 다른 상황으로 이동한다.
4. 지도는 위치 비교, 상세는 방문 조건 확인, 외부 지도는 출발지·경로 설정으로 이어진다.
5. 동행자에게는 두 장소가 유지되는 ‘비교 링크’를 복사한다.

## 공개 자료 보완

읽을 수 있었던 공예박물관·서울한옥포털·관광공사 자료의 범위에 맞춰 정보를 보완했다.
대표 전화는 공개된 기관·매장 번호 세 개만 사용한다. 이번에 원문을 다시 확인하지 못한
어니언·정독·이상의 집은 ‘기존 수집 자료·재확인 필요’로 표시한다.
스태픽스의 서로 다른 편의시설 표로 무단차 접근을 보장하지 않는다.
[장소별 출처·남은 사항](../CONTENT_SOURCES.md)

## 리소스 크기

| 리소스 | 이전 파일 바이트 | v20 파일 바이트 |
| --- | ---: | ---: |
| UI 글꼴 | 2,057,688 | 125,144 |
| 첫 비교 쌍의 목록 사진 2장 | 835,789 | 65,444 |
| 목록용 사진 8장 합계 | 3,539,033 | 280,572 |
| MapLibre JS | 1,056,837 | 파일 유지, 모바일 목록에서 지연 로드 |

로컬 파일 크기이며 실제 HTTP 전송량·통신 속도·초 단위 로딩 시간을 뜻하지 않는다.
브라우저의 lazy 이미지 선로딩 범위는 기기별로 다를 수 있다.
목록/지도는 작은 WebP, 상세는 큰 WebP를 사용한다. 미리보기 실패 시 원본 JPG로
재시도한다. 원본 이미지와 원본 폰트는 삭제하지 않았다.

글꼴은 Pretendard의 형태·가변 굵기를 유지하고 필요한 UI 문자만 포함했다.
OFL의 예약 이름 조건에 따라 파생 폰트는 Alley Sans로 명명했다.
새 문구를 추가하면 `python scripts/build_preview_assets.py`를 실행한다.
파일별 크기와 이미지 치수는 `images/places/optimized/manifest.json`에 있다.

## 대표 화면 관찰

브라우저 미리보기에서 직접 본 내용만 기록한다. 자동 테스트를 추가하거나 실행하지 않았다.

- **390×844 목록:** 사진·비용·운영 표 렌더링. 지도 라이브러리 스크립트 요소가 생성되지 않은 상태 확인.
- **390×844 쌍 지도:** 목록 버튼 Enter 후 초점이 `map-title`로 이동. 정독도서관 선택 후 시간·휴관·비용·사진 표시.
- **390×844 이름 목록:** 하단 높이 282px, 목록 clientHeight/scrollHeight 모두 206px. 마지막 항목 하단 y829로 844px 안에 표시.
- **비교 복귀:** ‘비교 보기’ Enter 후 원래 ‘어니언 안국, 정독도서관 지도에서 비교’ 버튼으로 초점 복귀.
- **공예박물관 상세:** 첫 요약에 관람·예약 링크, 대표 전화, 유효한 임시 야간 안내 표시.
- **320×568 이름 목록:** 지도 160px, 하단 247px, 목록 144px 안에 206px 내용. 스크롤 안내 표시. 문서 높이 568px, 가로 넘침 없음. 마지막 ‘이상의 집’ 선택 후 대략 위치·운영·요금 확인 안내 표시.

실제 휴대폰·현장 보행·햇빛·엄지 도달성·화면 읽기 도구·운영체제 큰 글씨·네트워크 장애·
외부 지도 앱 왕복은 미실행이다. 위 관찰을 합성 100사례의 독립적인 실행으로 세지 않는다.

## 100개 조건 추적

`upgrade_v20_cases.csv`는 기존 S001–S100의 순서·지역·비교쌍·사용 조건을 보존하고,
각 행의 관련 R문제에 v20 구현을 연결한다. 남은 실제 확인은 삭제하지 않았다.
`python research/build_upgrade_v20.py`로 재생성하며 생성기는 문서 변환 도구다.
`upgrade_v20_evidence.json`은 대상 파일의 해시와 범위를 기록한다.

## 다음에 필요한 자료

1. 장소별 정확한 입구 사진·좌표, 문턱/경사/계단 없는 실제 경로.
2. 관람·구매·프로그램별 현재 가격, 예약 조건, 실제 머무를 수 있는 방식.
3. 안국·서촌에서 실제 사용자가 두 곳 중 고르고 출발하는 과정의 관찰.

위 정보가 없는 동안 새 필터·실시간 영업·혼잡도·AI 추천·계정 기능은 추가하지 않았다.
