# 합성 평가를 반영한 v18 업그레이드

2026-09-29. 입력: SYNTHETIC_GUIDE.md, SYNTHETIC_REVIEW.md, synthetic_cases.csv.
합성 사례는 개선 가설이다. 실제 이용자 성과나 성공률을 생성하지 않았다.

## 반영한 변화

1. 떠 있는 지도 버튼을 지역 선택 옆 상단 툴바로 이동했다. 문서의 마지막 여백만 늘리는 방식이 아니라 본문 위의 고정 오버레이 자체를 제거했다.
2. 쉬기·바깥 풍경·전시·옛 이야기로 바로 이동하는 메뉴를 추가했다. 지역 선택 시 해당 지역의 상황만 보인다.
3. 카드의 중복 비교 이유 문장을 제거하고 사진·방문 목적·공간·비용을 유지했다. 비교 값 15px, 보조 라벨 13px로 조정했다.
4. 상세를 장소명 → 기본 운영 요약 → 방문 전 확인 사항 → 상대 장소 → 사진 순서로 바꿨다. 운영 예외·휴무 전문과 출처는 펼쳐볼 수 있다.
5. 상대 장소 링크를 상세 상단으로 옮겼다. 전체 높이 상세, 목록 복귀, 출처 정보는 유지했다.
6. 링크 복사를 추가했다. 클립보드가 지원되지 않거나 거절되면 직접 선택해 복사할 입력란을 제공한다. 계정이나 즐겨찾기 서버는 추가하지 않았다.
7. 사진에 외관·마당·실내 등의 설명을 붙였다. 입구 사진이 아닌 계곡·박물관 실내 사진을 구분했다. 로딩·실패 상태도 표시한다.
8. ‘길찾기’를 실제 연결 기능인 ‘네이버 지도에서 보기’로 변경했다. 장소 검색 후 출발지와 경로를 설정한다는 안내를 추가했다.
9. 지도 핀을 기본 HTML button으로 바꿨다. Enter·Space 조작을 브라우저 기본 동작으로 제공하고, 선택할 때 포커스가 있는 버튼을 교체하지 않는다.
10. 선택한 장소 정보를 지도 위로 옮기고 현재 위치·도보 경로가 이 앱 지도에 없다는 점을 설명했다. 지도 일부 실패가 다른 타일 성공으로 즉시 지워지지 않도록 관리하며 재시도를 제공한다.

## 100개 사례와의 연결

upgrade_v18_cases.csv에 기존 S001–S100 각각의 변경 내용과 반영/부분 반영/보류를 연결했다. map_upgrade_cases.py로 생성한다. 원래 합성 피드백과 실제 조사 양식은 덮어쓰지 않았다. CSV의 상태는 구현 대응 상태이며 새로운 사용자 평가 결과가 아니다.

## 화면 확인 범위

390px 폭의 인앱 브라우저에서 수정된 목록과 상세 배치를 살펴봤다. 운영 요약·상대 장소 링크가 사진보다 위에 나타난다. 지도에서 Enter로 수성동, Space로 스태픽스를 선택했을 때 선택 장소 정보가 바뀌었다. 실제 iOS/Android, 스크린리더, 야외 보행 조사는 아니다. 자동 테스트 스위트는 추가하거나 실행하지 않았다.

## 남아 있는 정보·외부 조건

- 수성동·이상의 집 정확한 입구 좌표, 일부 비용·접근성·좌석 조건은 미확인 상태를 유지한다. 이번 추가 공식 자료 조회로도 입구 좌표·최신 관람료를 확정하지 못했다.
- 운영 요약은 기존 출처의 게시 정보를 축약한 것이다. 실시간 운영 상태를 계산하거나 표시하지 않는다.
- 사진 6장의 공개 배포 이용허락은 별도 확인이 필요하다. 로컬 앱만 수정했다.
- 다국어, 실시간 혼잡도, 현재 위치 GPS, 완전한 오프라인 사용, 실제 외부 지도 앱 왕복은 구현 범위 밖이다. 필요성·자료를 확인한 후 별도 판단한다.
- 느린 네트워크와 오프라인 안내는 구현했으나 장애를 주입하는 시험은 실시하지 않았다.
