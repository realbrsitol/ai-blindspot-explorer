# 지도 UX/UI 개편 v19

2026-09-29. 합성 평가 및 지도 화면의 사용성 진단을 구현으로 반영했다. 실제 사용자 조사 결과가 아니다.

## 적용 순서

1. **지도와 선택 정보의 동시 노출**: 지도 전용 모드에서 소개·상황 메뉴·결과 수를 숨겼다. 지도 아래 220px 카드 공간을 확보해 사진·장소명·공간·비용·행동이 핀을 덮지 않게 했다. 낮은 화면에서는 문서 스크롤을 허용한다.
2. **장소명 우선**: 지도 번호 1A/1B를 제거하고 Pretendard 장소명 버튼으로 바꿨다. 실제 좌표에는 작은 점을 남긴다. 버튼은 기본 HTML 버튼이며 키보드 조작과 선택 상태를 제공한다.
3. **겹침과 비교 맥락**: 화면 좌표에서 이름 영역이 겹치면 동네별로 묶는다. 묶음을 누르면 확대와 이름 선택 목록을 제공한다. 두 곳 비교에서는 해당 두 장소만 보여주며 이름을 점의 위/아래에 배치한다. 하단 이름 버튼, 상세, 비교 목록 간 이동을 연결했다.
4. **배경 단순화**: Leaflet 래스터 타일의 흑백 필터를 MapLibre + OpenFreeMap 벡터 지도로 교체했다. 흰 배경·웜그레이 도로와 공원, 확대 시 건물, 한국어 우선 라벨을 사용한다. 일반 상업 POI·등고선·도로 번호·공항·행정 경계를 제외했다. 주요 도로와 역 이름을 유지한다. 지도 스타일은 저장소에서 수정할 수 있다.
5. **거리·방향·위치 신뢰도**: 미터 축척, 북쪽 고정 안내, 지도 밖 확대·축소 버튼을 추가했다. 수성동 계곡·이상의 집은 점선과 대략적 위치 문구를 유지한다. 다른 좌표도 장소 대표 위치이며 입구 좌표가 아님을 선택 카드에서 밝힌다. 임의 경로·도보시간은 생성하지 않았다.

## 관련 파일

- `css/map-view.css`: 지도 전용 레이아웃, 이름 핀, 카드, 제어 버튼.
- `js/map.js`: 지도 초기화, 화면상 이름 충돌 묶음, 두 장소 비교, 카드, 오류 복구.
- `maps/alley-style.json`: 앱 전용 지도 스타일.
- `scripts/build_map_style.py`: 저장된 Positron 원본에서 스타일 생성.
- `vendor/maplibre/`: npm 공식 배포 MapLibre GL JS 5.24.0, CSS, 라이선스.

지도는 OpenFreeMap/OpenMapTiles/OpenStreetMap 출처를 유지한다. UI와 DOM 장소명은 로컬 Pretendard, 벡터 라벨은 Noto Sans 글리프와 로컬 한글 글꼴 설정을 사용한다.

## 적용 범위와 남은 확인

390×844 인앱 브라우저 미리보기에서 배경 지도 로딩, 이름 묶음 펼치기, 장소 선택, 두 곳 비교 카드가 함께 나타나는 배치를 살펴봤다. 실제 휴대폰·야외 보행·스크린리더 조사는 하지 않았다. 자동 테스트는 추가하거나 실행하지 않았다.

벡터 지도는 WebGL과 외부 타일 연결에 의존한다. 불러오지 못하면 재시도 안내 및 별도의 장소 이름 선택을 제공한다. 실제 장애 주입 시험은 하지 않았다. 새 라이브러리 번들은 Leaflet보다 크므로 저사양 단말의 초기 로딩 시간은 별도 측정이 필요하다.

정확한 입구 좌표가 미확인인 두 장소, 사진 6장의 배포 이용허락, 운영시간의 실시간성은 이번 UI 작업으로 해결됐다고 주장하지 않는다. 로컬 프로젝트에 적용했으며 배포하지 않았다.
