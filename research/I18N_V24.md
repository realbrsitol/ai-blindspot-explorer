# 다국어 지원 v24

## 제공 범위

한국어(ko), 영어(en), 일본어(ja), 중국어 간체(zh-CN)를 제공한다. 상단과 장소 상세의 언어 선택 메뉴에는 각 언어의 이름을 원어로 표시한다.

- 19개 장소의 이름, 비교 목적, 비용, 운영·휴관, 설명, 주소, 이용 방식, 방문 팁, 이동 편의, 미확인 사항과 사진 설명.
- 12가지 비교의 제목·이유·방문 제약. 어린이관과 기념품점의 용도별 정보도 별도 번역.
- 지역·목적 필터, 더 보기, 지도 선택과 상태 안내, 공유·복사 메시지, 대체 텍스트와 접근성 이름.
- 날짜가 있는 공지와 만료 후 안내. 번역이 기존 요금·예약·불확실성을 새 사실로 바꾸지 않도록 원문의 구분을 유지.

한국어 원본은 `js/data.js`, `js/expansion.js`를 사용한다. 번역은 앱용 편집본이며 운영기관이 인증한 번역이나 새로운 현장 조사 결과가 아니다. 방문 정보의 근거는 기존 `CONTENT_SOURCES.md`를 따른다. 외부 웹사이트와 현장의 외국어 응대는 앱 언어와 별개다.

## 방문 현장에서 필요한 기능

- 번역 화면에도 상세의 한국어 장소명·주소를 별도로 표시하고 `lang="ko"`를 지정한다.
- 한국어 주소 복사 버튼과 클립보드 실패 시 직접 복사할 입력란을 제공한다.
- 네이버 지도 검색에는 번역된 명칭 대신 원본 한국어 장소명·주소를 전달한다.
- 외국어 화면의 공개 전화 링크는 국가번호 +82를 사용한다.
- 영어 참고 링크가 있는 경우 유지한다. 공식 자료의 언어를 임의로 바꾸거나 없는 외국어 예약 페이지를 만들어 연결하지 않는다.

## 언어와 상태

지원하는 URL `lang` → 저장된 명시적 선택 → 한국어 순으로 결정한다. 브라우저 언어만으로 자동 전환하지 않는다. 선택은 로컬 저장소에 기록하며 저장소가 막혀도 URL로 동작한다. 공유 링크와 홈 링크에 언어를 포함한다.

언어를 바꾸면 같은 경로를 새 언어로 다시 연다. 지역·목적·지도·비교·상세 URL을 유지하고, 세션 저장소가 가능하면 펼친 목록 수와 선택 장소·목록 위치도 복원한다. 상세에서 언어를 바꾼 뒤 닫아도 새 언어를 유지한다. 지도 카메라의 수동 이동 위치까지 저장하지는 않는다.

## 구현과 유지보수

`js/i18n.js`가 선택한 언어의 JSON과 공통 UI 사전을 같은 서버에서 읽는다. 외부 번역 API, 계정, API 키는 없다. 번역 파일을 읽지 못하거나 장소·비교 항목이 빠진 경우 한국어로 복귀하고 재선택 안내를 보여준다.

- `js/locales/ui.json`: 한국어 UI 문구 → `[영어, 일본어, 중국어 간체]`.
- `js/locales/en.json`, `ja.json`, `zh-CN.json`: `places`, `pairs`, `mapNames`, `notices`.
- `places`의 16개 필드는 순서대로 `name, category, visitWhen, cost, schedule, closure, description, address, hours, useMode, visitTip, accessSummary, access, unknown, checkLabel, photoLabel`이다. 순서는 `js/i18n.js`의 `fields`와 일치해야 한다.
- `pairs.choices`는 한국어 원본의 예약 URL·공지·검토 범위 같은 메타데이터를 유지하고 번역 문구를 덮어쓴다.
- 항목을 추가하거나 방문 정보가 바뀌면 세 언어를 함께 갱신해야 한다. 번역의 출처 확인일을 새 조사일처럼 자동 갱신하지 않는다.

한국어·라틴 문자는 기존 Alley Sans를 사용한다. 일본어는 Hiragino/Yu Gothic/Meiryo, 중국어 간체는 PingFang SC/Microsoft YaHei/Noto Sans CJK SC 등 기기의 글꼴을 사용한다. 한·중·일 혼합 글자 형태를 한글 서브셋으로 덮어쓰지 않는다. 외부 웹폰트는 추가하지 않았다.

바탕 지도는 해당 언어 지명이 있으면 사용하고, 없으면 영어, 그다음 원래 이름으로 폴백한다. 개별 장소 핀과 아래 목록은 앱 번역을 사용한다. 긴 지도 이름은 짧은 이름 또는 말줄임을 사용하며 전체 명칭은 선택 카드와 접근성 이름에서 유지한다.

## 작업 범위

로컬 정적 앱에 반영했다. 자동 테스트를 추가하거나 실행하지 않았으며, 실제 관광객·현지 원어민에 의한 사용성·번역 검토는 수행하지 않았다. 로컬 브라우저 미리보기와 글꼴·미리보기 자산 생성은 구현 작업에 포함된다.

로컬 브라우저에서 영어·일본어·중국어 간체의 목록, 중국어 상세의 한국어 주소, 상세를 유지한 언어 전환과 복귀, 영어 지도 지명·조작부 표시를 살펴봤다. 해당 미리보기에서 브라우저 오류 로그는 없었다. [영어 목록](i18n-v24-en.png) · [영어 지도](i18n-v24-map-en.png)
