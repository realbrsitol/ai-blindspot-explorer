# v19 합성 사용 재평가

작성: 2026-09-29. 대상: localhost:8765, UI/지도 v19, 장소 데이터 v18.

**실제 참가자 0명.** 기존 100개 합성 사례를 현재 화면과 코드에 다시 연결했다. 개별 사례별 100회 브라우저 실행은 하지 않았다. 실제 영업 정보·현장 접근성은 재조사하지 않았다. 이번 작업은 평가 문서와 사례 대응표만 작성했으며 앱 코드는 수정하지 않았다.

## 결론

다음 개선의 중심은 **두 곳을 방문할 수 있는지 판단하는 정보를 한곳에 모으고, 확인이 필요한 항목에 바로 행동할 수 있게 하는 것**이다. 새 색상이나 탐색 기능을 추가할 근거는 부족하다.

사진·동일 항목 비교·상대 상세 전환·이름 지도·축척은 유지한다. 남은 문제는 운영·비용·입구 정보의 빈칸, 첫 화면 중복, 지도 카드의 숨은 스크롤, 지도 진입 초점, 초기 다운로드다.

### 근거를 더 모은 뒤 선택 — P3

GPS, 다국어, 즐겨찾기, 화장실·충전·아동 동반 필터, 진행 중인 전시 목록은 사용 조건에 따라 유용할 수 있다. 기존 100개 가정만으로 수요·정보 공급 가능성을 입증하지 못했다. 특히 ‘쉴 곳’의 의미가 앉기·대화·음료·조용한 열람 중 무엇인지 먼저 확인한다. 새 리뷰/점수/AI 추천/가입 기능은 현재 개선 목록에 추가하지 않는다.

바이트는 로컬 파일 크기다. HTTP 압축·캐시·동시 다운로드·실제 전송량·초 단위 로딩을 측정한 값이 아니다. 지도 JS는 이전 라이브러리보다 파일 크기가 약7.16배다. 지도 배경 품질 개선의 유지 여부와 별개로, 목록까지 이 파일 실행 순서에 묶을 필요는 없다. defer 스크립트는 문서 순서대로 실행된다. [MDN script 설명](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/script#defer)

## 5. 100개 사례를 다시 읽는 방법

`recheck_v19_cases.csv`에 기존 S001–S100을 보존했다. 각 행에 v18 대응 상태, 현재 UI/CODE 근거, 관련 R문제, 비교쌍별 남은 질문, 다음 확인을 연결했다. 대표 UI 관찰이 모든 사례에서 실행된 것처럼 기록하지 않았다.

예를 들어 ‘한 손 사용’은 버튼 가림이 없어졌어도 실제 엄지 도달성이 확인된 것은 아니다. ‘큰 글씨 선호’도 기본 글씨를 키운 구현만으로 기기 글자 확대가 검증된 것은 아니다. v18의 ‘반영’은 구현 대응 상태이며 실제 불편 해소 판정으로 확장하지 않는다.

## 6. 추가로 빠져 있던 상황

기존 100개 사례의 조건을 변경하거나 새 참가자처럼 세지 않고 다음 점검 조건을 별도로 추가한다.

- 두 후보 모두 정기 휴관인 날, 전시 없음/프로그램만 운영하는 날.
- ‘무료’ 공간에서 대화·앉기·음식 같은 실제 목적을 충족하지 못하는 경우.
- 지도는 불필요한데 네트워크가 느린 첫 방문.
- 지도가 15초 이후 정상 표시되는 회복 상황.
- 지도 카드에서 8번째 장소를 찾는 경우.
- 키보드로 비교 화면과 지도를 왕복하는 경우.
- 임시 야간 운영 종료 후의 재방문.
- 한 장소가 아니라 비교 중인 두 장소를 동행자에게 보내는 경우.
- 화면이 좁은 상태에서 큰 글씨도 함께 사용하는 경우.
- 공식 확인 링크가 로그인·외국어 페이지를 요구하거나 필요한 정보를 바로 보여주지 않는 경우. 실제 외부 페이지 탐색은 이번에 실행하지 않았다.

## 7. 유지할 성과와 확인하지 않은 범위

확인한 개선: 비용 행 가림 제거, 상황별 바로 이동, 상대 상세 전환, 사진 내용 설명, 지도/선택 카드 분리, 이름 기반 선택, 축척·북쪽 표시, 현재 목록 맥락으로 복귀.

미실행: 실제 참가자·현장 보행·현재 운영 재확인·유모차/휠체어 동선·야외 햇빛·실제 한 손 조작·화면 읽기 도구·폰 글자 확대·외부 지도 앱 왕복·네트워크/오프라인 장애 주입. 불편 빈도, 전환율, 만족도 점수는 산출하지 않았다.

320px 리플로, 초점 가림, 조작 대상 크기를 참고 기준으로 사용했지만 WCAG 적합성 판정은 하지 않았다. 지도 자체의 2차원 이동 예외를 주변 카드의 줄바꿈까지 확장하지 않는다. [W3C 리플로](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html) · [초점 가림](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html) · [조작 대상 크기](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)
