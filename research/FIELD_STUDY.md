# 안국·서촌 현장 사용성 조사 — 100명

상태: 실행 준비. 실제 모집 0명, 실제 응답 0건. 이 문서는 결과 보고서가 아니다.

## 1. 조사 목적과 범위

조사 시점에 실제 안국·서촌에 있는 사람들이 자신의 휴대폰으로 앱을 사용하고, 장소를 선택하고, 실제 골목에서 선택한 장소까지 찾아가도록 한다. 사람들이 외형을 마음에 들어 하는지보다 선택과 이동을 어디서 어려워하는지 관찰한다.

- 완료 목표: 안국 50명 + 서촌 50명 = 100명.
- 성인 본인이 자발적으로 동의한 경우 참여한다. 나이·직업·거주 여부를 외모로 추정하지 않는다.
- 앱의 한국어 내용을 읽기 어려운 사람을 만난 경우 언어 장벽으로 기록한다. 한국어 사용 참가자의 결과를 모든 관광객에게 일반화하지 않는다.
- 주민·근무자·방문객은 본인이 답한 선택 항목으로 구분한다. 지인, 개발 관계자, 이전 참여자를 편의상 채워 넣지 않는다.
- 조사원은 한 사람과 동행한다. 동행 친구의 답을 참가자 본인의 답과 합치지 않는다.

## 3. 현장 모집: 임의로 마음에 드는 사람을 고르지 않기

거리의 모든 사람을 알 수 없으므로 전체 방문객에 대한 단순 무작위 표본은 만들 수 없다. 정해진 장소·시간대 안에서 무작위 시작점을 사용하는 체계적 현장 표집으로 진행한다. 응답 거절과 시간대에 따른 편향은 남는다.

1. 공개 보행 구간에서 통행을 방해하지 않는 지점을 정하고 블록 ID, 날짜, 시간대, 모집 지점 이름을 적는다. 특정 가게 고객이나 대기 줄만 모집하지 않는다.
2. 각 모집 블록 시작에 주사위를 한 번 던진다. 1·2면 첫 번째, 3·4면 두 번째, 5·6면 세 번째 보행자를 첫 접촉 대상으로 한다. 결과를 기록한다.
3. 정한 방향으로 기준선을 지나는 사람을 세고, 첫 접촉 뒤에는 매 세 번째 사람에게 동일한 문구로 요청한다. 일행도 통과 순서대로 세며, 성인 여부는 요청 시 확인한다. 아동으로 확인되면 제외하고 다음 정해진 순번을 따른다.
4. 거절하면 곁의 사람에게 바로 대체 요청하지 않는다. 다음 정해진 순번까지 센다. 외모, 스마트폰 종류, 언어 추정으로 골라 건너뛰지 않는다.
5. 혼자 진행할 경우 참여자가 정해지면 모집을 멈추고 동행한다. 다음 모집 재개 때 새 블록으로 기록하고 시작 순번을 다시 추첨한다. 따라서 해당 시간대 전체 보행자를 대표하지 않는다는 한계가 있다.
6. 거절 사유는 자발적으로 말한 경우만 넓은 범주로 기록한다. 거절자의 이름·사진·외모·연락처는 기록하지 않는다.

## 4. 모집·동의 문구

> 안녕하세요. 안국·서촌에서 갈 곳을 비교하는 앱을 개선하고 있습니다. 지금 개인 휴대폰으로 장소 두 곳을 살펴보고 한 곳을 골라 실제 입구까지 걸어가는 조사입니다. 약 25~35분을 예상하지만 선택한 장소에 따라 달라질 수 있습니다. 사람을 평가하는 조사가 아니며, 이용 중 어려운 점을 보고 싶습니다. 성인이며 자발적으로 참여하실 의향이 있으신가요?

동의 전 실제 보상 조건, 담당자, 기록 보관·삭제일을 채워 설명한다.

> 원하시면 언제든 그만두거나 질문에 답하지 않으셔도 됩니다. 구매나 유료 입장은 필요하지 않습니다. 이름·연락처·정확한 이동 경로를 수집하지 않고 참가 번호로 기록합니다. 기본적으로 얼굴 촬영, 음성 녹음, 화면 녹화는 하지 않습니다. 익명 행동 메모와 답변을 앱 개선에 사용해도 될까요?

동의하지 않으면 조사 과제를 시작하지 않는다. 보상 지급에 연락처 등이 필요해지면 조사 답변과 분리된 절차를 마련한 뒤 안내한다. 이 양식에는 연락처를 적지 않는다.

## 5. 진행 순서와 과제 문구

### 시작 — 약 3분

- 참가 번호 P001부터 실제 동의 순서대로 부여한다. 아직 모집하지 않은 사람을 기록하지 않는다.
- 본인 휴대폰·모바일 데이터로 접속한다. 기기 정보는 iOS/Android/기타만 기록하고 기기 식별자는 수집하지 않는다.
- 이 동네 방문 빈도, 오늘 온 이유를 묻는다. 앱의 버튼 위치나 비교 구조를 먼저 설명하지 않는다.

### 과제 1: 두 장소 중 선택 — 약 5분

해당 블록의 상황 문구 하나만 읽는다.

- 어니언–정독: “이 동네에서 잠깐 쉬어갈 곳을 고르려고 합니다. 앱에 나온 두 곳을 살펴보고 지금 가고 싶은 곳을 정해 주세요.”
- 공예박물관–배렴: “이 동네에서 전시나 문화공간을 한 곳 둘러보려고 합니다. 두 곳을 살펴보고 지금 가고 싶은 곳을 정해 주세요.”
- 스태픽스–수성동: “바깥 풍경을 즐기며 시간을 보내려고 합니다. 두 곳을 살펴보고 지금 가고 싶은 곳을 정해 주세요.”
- 대오–이상: “이 골목의 옛 이야기가 있는 공간을 둘러보려고 합니다. 두 곳을 살펴보고 지금 가고 싶은 곳을 정해 주세요.”

자연스럽게 양쪽을 봤는지 먼저 기록한다. 한쪽만 봤다면 선택 기록 후 “다른 장소에 관해서도 궁금한 정보를 찾아 주세요”를 추가 과제로 제공하고, 자발적 탐색과 과제로 유도한 탐색을 구분한다.

### 과제 2: 위치 파악 — 약 3분

> 선택한 곳이 어디에 있는지 확인하고, 어떻게 찾아갈지 보여 주세요.

“지도 버튼”, “핀”, “노란색” 등의 답을 알려주지 않는다. 외부 지도 연결 전후를 구분해서 기록한다. 지도 앱 설치나 로그인은 강요하지 않는다. 접속 실패나 데이터 사용 거절도 관찰 결과로 남긴다.

### 과제 3: 실제 골목에서 이동 — 약 10~20분, 경로에 따라 변동

> 편하시면 이제 고른 곳의 입구까지 찾아가 주세요. 이동할 때는 안전한 곳에 멈춰 화면을 확인해 주세요.

- 조사원은 길을 유도하지 않고 동행한다. 참가자의 정밀 GPS 궤적을 저장하지 않는다.
- 지도에서 위치를 이해했는지, 앱과 외부 지도를 어떻게 오가는지, 도착지와 입구를 혼동하는지 메모한다.
- 구매와 실내 입장은 요구하지 않는다. 외부 입구 도착을 기본 종료점으로 삼는다.
- 위험·피로·기상 문제·참가자 요청이 있으면 즉시 중단한다. 중단 사유는 앱 오류와 구분한다.
- 폐점·휴관이면 운영 정보 문제로 기록한다. 강제로 다른 곳을 고르게 해 원래 실패를 지우지 않는다.

### 과제 4: 다시 비교 — 약 2분

> 다시 앱으로 돌아와 방금 비교하던 두 장소를 찾아 주세요.

기존 위치로 복귀했는지, 브라우저·외부 지도 전환에서 길을 잃었는지 기록한다.

### 마무리 — 약 3분

1. 어떤 점 때문에 그 장소를 골랐나요?
2. 두 장소를 비교할 때 빠져 있던 정보가 무엇인가요?
3. 쓰면서 가장 막혔던 순간은 언제였나요?
4. 화면에서 없어도 되겠다고 느낀 것이 있나요?
5. 글씨와 사진을 야외에서 보기 어땠나요?
6. 장소 선택 / 길 찾기는 각각 얼마나 쉬웠나요? 1 매우 어려움 ~ 7 매우 쉬움.
7. 앱에 쓰인 내용과 현장이 다른 점이 있었나요?

“깔끔하지 않나요?”, “노란색이 좋죠?”처럼 답을 유도하지 않는다. 개선 제안과 실제 관찰 행동을 따로 적는다.

## 6. 기록 규칙

- `recruitment.csv`: 모집 블록마다 접촉·거절·비대상·동의 인원을 기록한다. 반응 없는 사람은 거절에 포함한다.
- `sessions.csv`: 실제 동의자만 한 행씩 기록한다. 완료·중단·접속불가를 모두 남겨 완료자만 보고하는 편향을 피한다.
- `observations.csv`: 한 문제 또는 발언마다 한 행. 직접 인용과 조사원의 해석을 구분한다.
- 과제 결과: `독립성공`, `도움후성공`, `미완료`, `미실시` 중 하나.
- 도움을 요청하면 우선 “평소라면 어떻게 하시겠어요?”라고 묻는다. 실제 안내를 제공하면 도움후성공으로 기록한다. 막힘과 중단을 숨기지 않는다.
- 빈 값은 미수집이다. 0초 또는 쉬움 점수 0으로 대체하지 않는다. 시작·종료를 놓친 과제의 시간은 비워둔다.
- 선택하지 않은 참가자는 선택값을 비워두고 사유를 기록한다. 임의의 장소를 채우지 않는다.
- 참여 중단자를 채우기 위해 추가 모집하더라도 전체 동의자 수, 중단 수, 완료 수를 각각 보고한다. 완료 목표 100명과 총 동의자 수는 다를 수 있다.

## 7. 결과를 개선 우선순위로 바꾸는 방법

1. 잘못된 장소 안내, 실제와 다른 운영 정보, 접근 불가 등 방문을 실패시키는 문제.
2. 장소 선택·양쪽 상세·지도 전환·목록 복귀를 막는 문제.
3. 반복해서 발생한 글씨 읽기, 비교 항목 이해, 조작의 어려움.
4. 행동 문제로 이어지지 않은 개인 취향 의견.

문제별로 서로 다른 참가자 수를 센다. 한 사람이 같은 문제를 다섯 번 겪어도 영향 인원은 1명이다. 빈도만으로 우선순위를 결정하지 않고 실패의 영향과 근거를 함께 본다.

보고 항목: 전체 접촉 수, 동의 수, 완료 수, 중단 수, 언어 장벽 수; 과제별 독립성공/도움후성공/미완료/미실시 인원; 실제 시도자 분모; 과제 시간 중앙값과 측정 인원; 선택·길찾기 난이도 응답 분포; 주요 문제와 익명 발언.

100명은 모든 안국·서촌 이용자의 대표 표본이 아니다. 지역·시간대·익숙함별 차이는 탐색적으로 해석한다. 좋은 반응만 추려 내거나 AI로 빈 응답을 보충하지 않는다. 조사 중 앱 버전을 바꿔야 하면 변경 시점을 기록하고 버전별 결과를 분리한다.

## 8. 인력과 시간 산정

100회 × 25~35분 = 순수 진행 약 42~58시간이다. 모집 거절, 이동, 휴식, 기록 정리 시간은 별도다. 실제 소요시간은 현장에서 달라진다. 두 진행자가 독립적으로 한 세션씩 운영하면 각자 약 21~29시간의 순수 진행이 필요하다. 날짜와 인력 확정 전 조사 완료 일정을 약속하지 않는다.
