# 관광객 관점의 비교 확장 v23

작성·공개 자료 열람: 2026-09-29. 현장 조사와 실제 참가자 관찰은 하지 않았다. 기존 합성 100사례를 새로운 사용자 조사 결과로 재계산하지 않는다.

## 부족했던 선택

기존 4쌍은 카페·휴식·전시에 집중되어 있었다. 관광객이 하루 중 결정해야 하는 식사, 대표 유산, 직접 참여, 여행 선물, 비·더위 대안, 어린이 동반을 충분히 다루지 못했다. 장소를 무작위로 늘리지 않고 같은 방문 목적에서 서로 다른 경험을 고르는 비교를 추가했다.

| --- | --- | --- |
| 서촌 식사 | 통인시장 / 토속촌삼계탕 | 여러 가게에서 골라 담기 / 한 식당에서 식사, 도시락 종료시간, 음식 성분 문의 |

| 여행 선물 | 국립민속박물관 / 국립현대미술관 서울 | 전통문화 상품 / 현대미술 상품·책, 매장 시간과 전시 시간 구분 |

기존 휴식·풍경·공예 전시·골목 이야기 4쌍을 유지했다. **총 12가지 비교, 중복을 뺀 19개 장소**다. 박물관을 여러 목적으로 재사용하므로 24개 장소로 세지 않는다. 경복궁·고궁박물관은 서촌에서 이어지는 경복궁역 권역으로 묶고 카드에서 그 범위를 밝힌다.

## 정보량을 다루는 방식

- 동네와 6개 목적을 함께 필터링한다. ‘모두’는 전체 목적이다.
- 처음에는 4개를 표시하고 4개씩 더 펼친다. 전체 비교 수와 고유 장소 수는 상단에 표시한다.
- 카드는 사진·방문 목적·비용·기본 운영을 유지한다. 긴 예외, 접근 동선, 주소, 전화와 출처는 상세에서 읽는다.
- 두 곳 모두 어려울 때 펼치는 대안은 3개로 제한한다. 지역이 같은 비교, 목적이 같은 비교 순으로 고른다.
- 결과 없는 동네·목적 조합은 그 사실을 알리고 ‘두 동네에서 찾기’를 제공한다.
- 같은 장소도 선택한 비교에 따라 비용·예약 링크·운영 요약을 바꾼다. 어린이관 무료를 상품 가격으로 쓰거나 일반 전시의 야간개관을 어린이관 운영으로 쓰지 않는다.
- 지도는 장소를 ID로 중복 제거한다. 여러 비교를 가진 장소에서는 ‘비교 고르기’를 제공한다. 밀집한 이름은 일부 접되 점, 키보드 초점, 선택한 이름과 하단 장소 목록은 유지한다.

## 근거와 충돌 처리

공식 관광기관과 운영기관 공개 자료를 읽었다. 상세 출처 표는 [CONTENT_SOURCES.md](../CONTENT_SOURCES.md)에 있다.

- 고궁박물관 시간은 관광공사에 남은 이전 안내보다 운영기관의 09:30 개장 안내를 우선했다.
- 통인시장 도시락은 주말 종료시간·휴무·엽전 최소 구매액이 자료마다 달랐다. 현재 구매액을 단정하지 않고 확인 링크와 차이를 상세에 남겼다.
- 북촌문화센터 시설 목록과 2026년 운영표의 주말 시간이 달라 단일 시간을 확정하지 않았다.
- 운현궁 가을 야간개방은 2026-09-01~11-29 한시 안내로 분리했다.
- 민속박물관 상설전시관 1의 2026-09-30~12-21 예정 휴관을 기록했다. 기간 종료 후 자동으로 재개관했다고 표시하지 않는다.
- 음식점 가격, 대기, 알레르기 대응, 예약 잔여석, 상품 재고, 무단차 진입은 근거가 없는 확정값을 넣지 않았다.

## 사진·지도·글꼴

11곳의 실제 참고 사진을 추가했다. 원본 구도·비율·워터마크를 유지하고 480/960px WebP를 생성한다. 창덕궁 사진은 후원, 경복궁 사진은 경회루이며 입구 사진으로 소개하지 않는다. 기념품 비교의 사진은 건물 외관임을 밝힌다. [사진 출처](../images/places/README.md)

새 한글 문구를 포함해 Alley Sans 서브셋을 다시 생성했다. 흰색·차콜·웜그레이·노란색의 기존 색 체계를 유지했다.

## 로컬 화면 확인

브라우저의 키보드 탐색으로 목적 필터, 빈 결과에서 전체 동네로 복귀, 4→8→12개 펼치기, 어린이관 상세와 예약 링크, 기념품 비교 지도의 상품별 비용, 같은 미술관의 복수 비교 선택을 살펴봤다. 해당 흐름의 브라우저 오류 로그는 없었다. 실제 휴대폰의 터치·현장 이용은 확인하지 않았다. [첫 화면 캡처](expansion-v23-mobile.png)

## 남아 있는 조사 항목

- 서촌의 어린이 전용·직접 체험 선택지는 안국보다 적다. 일정을 확인할 수 있는 운영기관 자료가 더 필요하다.
- 화장실, 짐 보관, 충전, 채식·할랄, 무장애 이동은 현장성과 최신성이 중요한 별도 요구다. 현재 근거만으로 필터를 제공하지 않는다.
- 영문명과 확인된 영어 관광 안내를 일부 새 장소에 제공했지만 앱 전체의 번역이나 외국어 응대를 보장하지 않는다.
- 실제 관광객의 선택 성공률·예약 완료·도보 진입 관찰은 아직 없다. 자동 테스트는 이번 요청 범위에서 추가하거나 실행하지 않았다.
