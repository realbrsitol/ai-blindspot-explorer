# 합성 사용자 재평가 지침 v2

2026-09-29. v1을 재사용하면서 개편 후 회귀 문제와 판단 정보의 누락을 확인하기 위한 보완판.

## 유지하는 원칙

- 실제 참가자는 0명이다. 기존 S001–S100은 네 비교쌍 × 25개 가정 조건이다. 100명의 독립 사용, 인터뷰, 현장 보행으로 표현하지 않는다.
- `synthetic_cases.csv`의 ID·조건·기존 피드백은 변경하지 않는다. 새 평가는 별도 파일에 기록한다.
- UI는 이번에 직접 확인한 화면/조작, CODE는 현재 구현, HYP는 예상되는 불편, UNTESTED는 실행하지 않은 조건이다. 한 문제에 여러 등급이 있을 수 있다.
- ‘코드에 구현됨’, ‘대표 조작에서 작동함’, ‘실제 이용자에게 유용함’을 서로 다른 판정으로 취급한다.
- 사례 수를 불편의 빈도나 만족도로 환산하지 않는다. 같은 조건이 네 쌍에 반복된다는 점을 유지한다.
- 현장 좌석, 입구, 운영, 보행 시간, 요금, 접근 가능 여부를 추정으로 채우지 않는다.

## 이번에 추가한 질문

1. **결정에 충분한가?** 서로 다른 두 장소를 고르는 데 필요한 운영·비용·머무는 방식이 같은 화면에 있는가?
2. **둘 다 안 맞으면?** 휴관·비·보행 제약 때문에 두 후보를 모두 제외해도 기존 메뉴로 다른 선택을 찾을 수 있는가?
3. **확인할 수 있는가?** ‘확인 필요’ 바로 옆에서 해당 기관의 구체적인 안내를 열 수 있는가? 확인된 내용과 남은 질문이 분리돼 있는가?
4. **줄인 정보가 다시 쌓이지 않았나?** 번호·제목·분류·소개·공간 설명의 중복, 역할을 잃은 표기를 찾는다.
5. **새 배치의 부작용은?** 고정 카드가 빈 상태에서도 공간을 차지하는가? 내부 스크롤에서 마지막 항목이 숨는가?
6. **상태를 옮기면?** 목록→지도, 상세→상대 장소, 뒤로가기, 지역 변경 뒤 선택·초점·맥락이 유지되는가?
7. **첫 진입은 가벼운가?** 목록을 읽는 데 지도나 큰 글꼴 다운로드를 기다려야 하는가? 파일 크기와 실제 전송량·지연을 구분한다.
8. **시간이 지나면?** 임시 개관·전시 안내에 유효기간이 있는가? 자료 확인일은 항목별 검증을 설명하는가?
9. **공유하려는 대상은?** 한 장소와 두 장소 비교를 구분한다. 계정 없이 기존 URL로 해결할 수 있는지 먼저 본다.
10. **보여주지 않은 것이 정말 필요한가?** 좌석 형태·입구·비용 조건은 확인하고, 리뷰·AI 추천·다국어·GPS·다수 필터는 실제 수요 근거와 구현 비용을 함께 판단한다.

## 최소 실행 범위

- 390×844: 첫 비교 카드, 마지막 비교 접근, 상대 상세 전환, 목록 복귀, 지도 진입, 장소 선택, 전체 범위와 이름 목록.
- 320×568: 콘텐츠 가로 넘침, 하단 행동 접근, 내부/외부 스크롤 구분. 320px 확인을 실제 큰 글씨·400% 확대·스크린리더 확인으로 대체하지 않는다.
- 마우스/키보드: 활성화뿐 아니라 전환 후 초점 위치를 읽는다.
- 장애 상태: 실제 장애 주입이 없으면 코드 검토로만 표시한다. 로딩이 나중에 성공할 때 오류가 사라지는지도 검토한다.
- 외부 지도 연결: href 확인과 실제 앱 실행·복귀를 구별한다.

## 결과 기록 형식

`문제 ID / 현재 사실 / 증거 등급 / 영향을 받는 목적 / 최소 변경 / 추가 확인 / 우선순위`

우선순위는 P1(방문 판단·핵심 접근에 직접 영향), P2(읽기·조작·복귀 마찰), P3(근거 수집 후 선택)로 기록한다. 장애 재현이 없는 상황에서 P0 또는 출시 불가로 단정하지 않는다.

**정보 예산:** 화면마다 질문 하나를 중심으로 구성한다. 목록은 ‘두 곳의 차이’, 상세는 ‘방문 조건’, 지도는 ‘위치와 선택’, 외부 지도는 ‘출발점과 실제 경로’. 숫자 제한을 보편 법칙으로 만들지 말고 제안임을 밝힌다.

## 재사용 프롬프트

```text
현재 앱과 SYNTHETIC_GUIDE_V2.md를 사용해 기존 S001–S100을 다시 평가하라.
기존 불편을 복사하지 말고 현재 UI/CODE 근거로 유지·부분 개선·잔여·새 마찰·실행 미확인을 나눠라.
합성 반응을 쓸 경우 반드시 합성 발언이라고 표시하라.
비교→상세→지도→외부 지도→복귀의 각 단계에서 판단에 필요한 정보와 불필요한 중복을 찾는다.
개편이 새로 만든 로딩·내부 스크롤·초점·안내 중복도 점검한다.
모르는 사실을 추가 정보처럼 채우지 않는다. 새 기능보다 재배치·삭제·자료 보완을 우선한다.
모든 원래 ID를 보존한 별도 대응표와, 영향순 최소 수정 목록을 작성한다.
독립 사용자 100명, 성공률, 만족도, 실제 도보 시간을 만들어내지 않는다.
```
