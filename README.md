# AI 추천에 없는 안국·서촌

AI 추천이 지나친 골목의 선택지를 발견하도록, 안국·서촌의 장소를 사진과 지도로 나란히 비교하는 정적 모바일 웹앱입니다. 현재 36개 장소와 36가지 비교를 제공합니다.

## 사용 흐름

### 모바일 앱 화면 v27 — 현재

휴대폰에서는 화면 폭에 맞추고, PC에서도 최대 480px의 한 열 화면을 사용합니다. 하단 고정 **비교 / 지도** 탭으로 이동하며 동네 선택과 목적 선택은 상단에 유지됩니다. 목적 버튼을 누르면 9개 목적과 ‘모두’를 고르는 하단 선택창이 열립니다. 선택창과 장소 상세는 키보드 초점 및 닫기를 지원합니다.

사진·비용·운영 비교와 4개 언어는 유지하며, 상단 제목·사진 모서리·버튼 간격을 다듬었습니다. 화면 위아래의 안전 영역과 하단 탭 높이를 레이아웃에 반영했습니다. 사용자가 선택한 범위는 **모바일 앱처럼 보이는 화면**이며, 설치형 PWA나 앱스토어 패키지는 추가하지 않았습니다.

### 목적별 8곳 구성 v26

카페·차, 미술·전시, 무료 관람을 추가해 실제 목적을 9개로 늘렸습니다. ‘모두’까지 포함하면 선택지는 10개입니다. **각 목적은 두 동네를 합쳐 4개 비교쌍·서로 다른 장소 8곳**을 제공합니다. 지역 필터를 선택하면 그 동네의 비교만 남습니다. 목적 간 장소 중복을 제외한 전체 고유 장소는 36곳입니다.

기본 메뉴는 짧게 유지하고 ‘모든 카테고리’로 펼칩니다. 무료 일반 관람과 유료 체험, 어린이관과 일반 동반 방문, 카페와 상품 구매를 구분합니다. 새 17곳의 사진·대표 위치·공식 방문 안내와 4개 언어 문구를 추가했습니다. [구성·선정 근거·전체 비교표](research/CATEGORY_EXPANSION_V26.md)

### 이름 변경 v25

앱 이름을 **AI 추천에 없는 안국·서촌**으로 변경했습니다. 모바일 상단은 두 줄로 배치하고, 브라우저·장소 상세 제목과 영어·일본어·중국어 이름을 함께 맞췄습니다. 소개 문구는 핫플과 골목의 다른 선택을 비교하는 취지를 담습니다.

### 다국어 지원 v24

상단과 장소 상세에서 한국어·English·日本語·简体中文을 선택합니다. 19곳과 12가지 비교의 방문 안내, 목적 필터, 지도·상세·복사·오류 안내를 번역했습니다. 선택한 언어는 URL과 로컬 저장소에 유지됩니다. 외국어 상세에는 현장에서 사용할 한국어 장소명·주소와 주소 복사를 제공합니다. [구현·번역 범위](research/I18N_V24.md)

### 관광객 관점의 비교 확장 v23

기존 네 비교를 유지하고 식사 두 쌍, 왕실 공간 두 쌍, 전통문화 체험, 어린이박물관, 비·더위 대안, 여행 선물을 더했습니다. 6개 목적(먹거리, 쉬기·산책, 문화·역사, 체험·선물, 비·더위, 아이와)과 동네를 함께 고를 수 있습니다. 첫 목록은 4개이며 ‘더 보기’로 나머지를 펼칩니다. 결과 수에는 비교 수와 중복을 뺀 장소 수를 따로 표시합니다.

같은 박물관도 어린이관·매장·일반 전시의 예약, 비용, 운영 안내를 구분합니다. 새 11곳의 사진·대표 위치·주소·공식 안내를 추가했고, 확인되지 않은 가격·예약 잔여석·접근성은 확정하지 않았습니다. 지도는 같은 장소의 핀을 중복 생성하지 않으며 여러 비교에 쓰이는 장소에서는 비교 목적을 선택할 수 있습니다. [선정과 반영 기록](research/CONTENT_EXPANSION_V23.md)

### 지도 재설계 v22

바탕지도를 도형 종류별 색 덮어쓰기 방식에서 큰길·골목·보행로·건물·공원·기준점의 22개 레이어로 다시 구성했습니다. 도로는 흰색 길과 얇은 경계로, 건물은 옅은 면으로 구분합니다. 주요 궁궐·공원·역 지명은 타일 데이터에 있는 정보로 표시합니다.

전체 지도는 서촌·안국 두 지역으로 시작합니다. 지역을 누르면 해당 장소의 점과 이름이 표시됩니다(v23부터 목적 필터 적용). 장소명 크기에 따른 자동 묶음은 제거하고, 이름을 점 주변 네 방향에 배치합니다. 지도 아래에 실제 장소 목록을 처음부터 표시하고 선택하면 사진·운영·비용·비교로 이어집니다. [재설계 기록](research/MAP_REDESIGN_V22.md)

### 합성 재평가 반영 v20

비교 카드에 비용과 기본 운영·휴관일을 나란히 배치하고, 바로 확인할 수 있는 출처 링크를 연결했습니다. 중복 번호·분류·공간 설명은 덜었습니다. 두 곳 모두 어렵다면 다른 상황을 펼쳐 이동하고, ‘비교 링크’로 두 장소가 함께 보이는 지도를 공유할 수 있습니다. 상세 첫 화면에는 관련 안내와 확인된 대표 전화가 있습니다.

지도 하단은 선택 상태에 따라 높이가 달라지며, 짧은 화면의 목록에는 스크롤 안내가 나타납니다. 지도 진입·복귀 초점을 연결하고 지연 로딩과 실제 실패 상태를 분리했습니다. 모바일 비교 화면에서는 MapLibre를 받지 않고, 지도가 보일 때 JS·CSS를 가져옵니다. [문제별 반영 기록](research/UPGRADE_V20.md) · [기존 합성 100사례 대응표](research/upgrade_v20_cases.csv)

### 지도 개편 v19

지도 전용 화면에서는 소개와 중복 안내를 접고, 지도 아래 고정된 공간에 선택한 장소의 사진·이름·비용·행동을 표시합니다. 번호 핀은 장소명으로 교체했습니다. 가까운 장소 이름이 겹치면 동네별 묶음으로 표시하며, 누르면 확대와 이름 목록을 함께 제공합니다. 두 곳 비교에서는 두 장소만 표시하고 하단에서 바로 전환합니다. 축척과 북쪽 표시를 추가하고, 확대·축소 버튼은 지도 위의 별도 도구막대에 두었습니다. [지도 개편 기록](research/MAP_V19.md)

### 합성 평가 반영 v18

지도 전환은 상단 툴바에 배치하고, 쉬기·바깥 풍경·전시·옛 이야기 바로 이동을 제공합니다. 상세 첫 화면에서 운영 요약과 방문 제약, 상대 장소 링크를 볼 수 있습니다. 링크 복사, 사진 내용 설명, 기본 HTML 버튼 지도 핀, 지도 실패 재시도를 추가했습니다. 네이버 지도 연결은 장소 검색 기능에 맞게 ‘네이버 지도에서 보기’로 표시합니다. [업그레이드 기록](research/UPGRADE_V18.md)과 [합성 100개 사례별 반영 내역](research/upgrade_v18_cases.csv)에 구현 내용과 미확인 사항을 구분했습니다.

### 장소 탐색

1. 안국 또는 서촌을 고릅니다.
2. 동네 버튼 오른쪽의 목적 버튼을 눌러 카테고리를 고릅니다. 두 장소의 실제 사진·방문 목적·비용·기본 운영을 나란히 비교합니다. ‘더 보기’로 나머지 비교를 펼칠 수 있습니다.
3. 어느 쪽을 눌러도 같은 상세 화면에서 주소·운영시간·출처·방문 팁을 읽습니다.
4. ‘네이버 지도에서 보기’로 장소를 검색한 뒤 출발지와 경로를 설정합니다.

흰색·차콜·웜그레이에 노란색 한 가지 강조색을 사용합니다. 양쪽 장소의 기본 시각적 비중은 같으며, 선택한 장소와 주요 행동만 노란색으로 표시합니다. 하단 ‘비교 / 지도’ 탭으로 전환하고 큰 화면에서도 최대 480px 앱 폭을 유지합니다. ‘두 곳의 위치 비교’는 해당 두 핀과 장소명을 표시하고, 지도 아래 ‘비교 내용 보기’는 해당 카드로 이동합니다. 목록으로 복귀하면 스크롤 위치를 복원합니다. 지역을 바꾸면 카드와 핀을 함께 필터링합니다. 상세는 전체 높이 화면이며 URL 직접 열기와 뒤로가기를 지원합니다. 설치형 앱이나 PWA는 아닙니다.

글꼴은 [Pretendard 1.3.9](https://github.com/orioncactus/pretendard)의 글자 형태와 가변 굵기를 유지한 UI 문자 서브셋을 로컬 제공합니다. OFL 예약 이름 조건에 따라 파생 파일은 **Alley Sans**로 이름을 바꿨으며 원본과 라이선스도 보존합니다. 장소명 18px/650, 비교 설명 15px/400, 상세 본문 16px/400으로 구분합니다. [글꼴 생성 기록](fonts/ALLEY_SANS.md)

실제 장소 사진 36장을 사용합니다. 정독도서관·수성동 계곡은 Wikimedia Commons 사진, 나머지 34장은 공식 관광·운영기관의 참고 사진입니다. 후자 34장은 공개 배포 전 이용허락 확인이 필요합니다. 출처와 확인 상태는 [사진 기록](images/places/README.md)에 기록했습니다. 사진은 원본 비율을 유지합니다.

MapLibre GL JS 5.24.0과 라이선스는 `vendor/maplibre/`에서 로컬 제공합니다. 배경은 OpenFreeMap 벡터 타일을 사용하며, 로컬 `maps/alley-style.json`에서 도로·건물·라벨을 따로 조정합니다. 흰 바탕과 웜그레이를 사용하고 일반 상업시설·등고선·도로 번호를 표시하지 않습니다. 건물은 확대 시 나타나며 주요 도로와 역 이름은 유지합니다. OpenFreeMap·OpenMapTiles·OpenStreetMap 출처를 지도에 표시합니다. 지도 배경에는 인터넷과 WebGL이 필요하며, 로딩 실패 시 재시도와 장소 이름 선택을 제공합니다. 이전 Leaflet 리소스는 현재 화면에서 로드하지 않습니다.

어니언·스태픽스·서울공예박물관·대오서점은 한국관광공사 위치 데이터, 배렴 가옥은 국가유산포털, 정독도서관은 OpenStreetMap 건물 중심을 사용합니다. 수성동 계곡과 이상의 집은 기존의 대략적 좌표이며 점선 핀으로 구분합니다. 현장 입구, 거리, 경로, 도보 시간은 검증하지 않았으며 표시하지 않습니다. 방문 정보의 근거와 남은 확인 사항은 [자료 확인 기록](CONTENT_SOURCES.md)에 정리했습니다.

`index.html`, `css/app.css`, `css/map-view.css`, `js/data.js`, `js/expansion.js`, `js/catalog.js`, `js/i18n.js`, `js/locales/`, `js/media.js`, `js/map.js`, `js/app.js`, `maps/alley-style.json`과 로컬 정적 리소스로 동작합니다. 앱 실행에 빌드 과정이나 API 키가 필요하지 않습니다. v26 내용은 `scripts/catalog_v26_content.py`를 편집하고 `python scripts/build_catalog_v26.py`로 생성합니다. 지도 스타일을 다시 생성하려면 `python scripts/build_map_style.py`를 실행합니다. UI 문구나 원본 사진을 수정한 뒤에는 `python scripts/build_preview_assets.py`로 글꼴 서브셋과 WebP 미리보기를 다시 생성합니다(Pillow·fontTools·brotli 필요). 원본 JPG는 보존하며 미리보기 실패 시 원본으로 재시도합니다.

```bash
python -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다.

## 이번 개편의 범위

이전 화면의 정책관 대시보드, 편향 차트, 시나리오 질의, 스탬프, GPS 레이더, 지도 위 임의 경로선과 PWA 구성을 제거했습니다. 36가지 두 장소 비교와 사진, 지역·목적 선택, 핀 지도, 장소 상세, 외부 지도 링크 및 4개 언어를 제공합니다. 실제 조사 자료가 연결되지 않은 486곳·92.2% 등의 수치도 화면에서 제거했습니다.

장소는 탐색 예시이며 실제 운영과 필요한 이용 조건은 각 장소의 확인 링크를 통해 다시 확인해야 합니다. 북촌로11길 일대 관광객 방문 제한은 화면의 서울한옥포털 공식 안내로 연결합니다.

이 저장소의 기존 `디자인.md`와 보고서는 과거 기획 자료입니다. 일부 수치는 보고서에서도 기획 가설로 명시되어 있으며, 현재 화면의 기능이나 검증된 조사 결과를 설명하지 않습니다.
